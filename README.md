# PeakClient

PeakClient is a server-driven client HUD and menu system for Minecraft 1.21.1 on Fabric and NeoForge. A server mod
describes an interface as a document (labels, panels, images, timers, minimaps, charts, entities, menus and more). The
PeakClient mod on the player's client renders it. Server mods only talk to the `PeakClient` API and never touch the network
layer.

It is built for events and minigames: scoreboards, killfeeds, voting, team scores, countdowns, waypoints and similar.
